# Rule Checklist

- [ ] YAML frontmatter is closed and parseable.
- [ ] Description is precise.
- [ ] Scope uses either justified `alwaysApply` or focused `globs`.
- [ ] Rule contains persistent, enforceable behavior.
- [ ] Paths, commands, contracts, and artifacts are verified.
- [ ] Rule does not duplicate complete agent or skill instructions.
- [ ] Prohibitions name the protected invariant.
- [ ] Validation obligations state required evidence.
- [ ] Documentation impact is explicit where relevant.
- [ ] Rule has no conflict or redundant overlap with another rule.

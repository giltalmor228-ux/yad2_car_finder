# Skill Checklist

- [ ] `SKILL.md` has closed YAML frontmatter.
- [ ] Frontmatter contains a stable name and trigger-rich description.
- [ ] Skill body is under 500 lines.
- [ ] Required input and optional evidence are clear.
- [ ] Workflow states are canonical and exhaustive.
- [ ] Risk routing uses observable project-specific criteria.
- [ ] Required gates cannot be bypassed.
- [ ] Revision loops are bounded and terminate.
- [ ] Blocked behavior preserves state and required next input.
- [ ] Every reference is one level deep and directly named.
- [ ] Every template has a producer and consumer.
- [ ] Skill orchestrates without duplicating specialist methods.
- [ ] Final readiness is explicit.
- [ ] Markdown fences and links are closed and valid.

# Agent Checklist

- [ ] Filename and frontmatter `name` match.
- [ ] Name is stable, lowercase, and unambiguous.
- [ ] Description states capability, project context, and observable triggers.
- [ ] Model is omitted unless explicitly approved.
- [ ] Tools are least-privilege and supported by the target environment.
- [ ] Role has one distinct decision responsibility.
- [ ] Trigger and non-trigger conditions are explicit.
- [ ] Preconditions and required inputs are explicit.
- [ ] Project-specific claims are evidence-backed or labeled.
- [ ] Invariants and realistic failure modes are covered.
- [ ] Method does not duplicate shared rules or the workflow skill.
- [ ] Output headings and decision vocabulary are strict.
- [ ] Stop conditions prevent unsafe or invalid continuation.
- [ ] Downstream handoff names a real agent or workflow stage.
- [ ] No secrets or sensitive runtime contents appear.
